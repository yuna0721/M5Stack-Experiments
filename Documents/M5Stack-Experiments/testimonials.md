# **プロジェクトを終えて**

## 習得したこと

- Gitについての基礎知識
- GitとLinux(VSCode)の同期
- Tagの使い方
- commitの使い方
- Markdown Fileの作成方法
- ソースコードの差分の見方

## 感想

　初めてGitというツールを使い、最初はわからないことだらけでとても大変でした。ことあるごとにエラーが出てくるので、課題自体が全然進まず、とても時間がかかりました。なので、いろいろ遠回りをしながらゆっくり基礎から学習しました。
このMarkdown Fileについても、段落や箇条書き、太字や斜体など、色々な要素を使って書いてます。

　今回の課題で一番驚いたことは、Gitはソースコードを書くのではなく、ソースコードを管理するものだと知ったことです。そして、Gitだけでなく、Linux（VSCode）を使ってTagやMarkdown Fileを作るということが、とてもややこしくて難しかったです（ちなみに、私はLinuxとVSCodeをSSH接続し、自分のPC1つで作業をしました）。

　本プロジェクトを終えて、いろいろなことを学びました。特に、Linuxの基本的なコードの使い方などはかなり習得できたと思います。この調子で、たくさんGitやLinuxを使い、扱い方に慣れていきたいと思います。コードなどを検索しなくても使えるように頑張ります。
